# Machine Learning Curriculum - From Fundamentals to Transformer Architecture

A comprehensive machine learning educational repository covering foundational concepts through advanced deep learning techniques including neural style transfer, object detection, and transfer learning.

## 📚 Project Overview

This repository contains a structured progression of machine learning projects and implementations, starting from mathematical foundations and advancing through supervised learning, unsupervised learning, and specialized deep learning architectures.

**Learning Path:** Mathematical Foundations → Data Processing → Supervised Learning → Unsupervised Learning → Advanced Deep Learning

## 📁 Repository Structure

### 1. **Math** - Mathematical Foundations
Essential mathematical concepts for machine learning:
- **linear_algebra/** - Vectors, matrices, and linear transformations
- **advanced_linear_algebra/** - Eigenvalues, eigenvectors, and matrix decomposition
- **calculus/** - Derivatives, gradients, and optimization fundamentals
- **probability/** - Probability theory and distributions
- **bayesian_prob/** - Bayesian statistics and inference
- **convolutions_and_pooling/** - Convolutional operations for neural networks
- **plotting/** - Data visualization techniques

### 2. **Pipeline** - Data Processing & Preparation
Real-world data handling and preprocessing:
- **pandas/** - Data manipulation and analysis with pandas
- **data_augmentation/** - Techniques for augmenting training datasets

### 3. **Supervised Learning** - Core ML Algorithms & Deep Learning
Predictive models and supervised techniques:

#### Traditional ML
- **classification/** - Binary and multi-class classification algorithms
- **decision_tree/** - Decision tree models and implementations
- **optimization/** - Optimization algorithms and techniques
- **regularization/** - Regularization methods to prevent overfitting
- **error_analysis/** - Error evaluation and model diagnostics

#### Deep Learning - Neural Networks
- **keras/** - Building neural networks with Keras/TensorFlow
- **cnn/** - Convolutional Neural Networks fundamentals
- **deep_cnns/** - Advanced CNN architectures and techniques

#### Specialized Architectures
- **transfer_learning/** - Transfer learning and fine-tuning pre-trained models
- **object_detection/** - Techniques for detecting objects in images
- **neural_style_transfer/** - Artistic style transfer using deep learning

### 4. **Unsupervised Learning** - Pattern Discovery
Self-supervised learning and unsupervised techniques:
- **dimensionality_reduction/** - PCA, t-SNE, and dimensionality reduction methods

## 🎯 Learning Objectives

- **Foundation:** Master mathematical concepts essential for ML (linear algebra, calculus, probability)
- **Data Processing:** Learn to prepare and augment datasets for training
- **Supervised Learning:** Implement and understand classical and deep learning algorithms
- **Advanced Topics:** Explore cutting-edge techniques like transfer learning, object detection, and neural style transfer
- **Unsupervised Learning:** Discover patterns and structure in unlabeled data
